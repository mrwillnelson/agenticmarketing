# Tools

These skills do not depend on a specific CMS, CRM, scheduler, scraper, or publishing stack. They accept pasted or exported material and write plain Markdown.

Use whatever tools you already use to capture calls, save notes, export posts, and review drafts. The public repo is intentionally limited to the writing layer:

| Need | Any tool that can provide |
|---|---|
| Transcripts | pasted call, podcast, webinar, or meeting text |
| Voice examples | 10 to 30 posts or essays written by the person |
| Performance review | posts with metrics, comments, or qualitative notes |
| Publishing constraints | platform modules in `platforms/` |
| Persistent context | the Markdown files in `my-story/` |

64stories uses a larger private operating stack to run the full GTM system for clients. That stack is not required for this public skills pack.
